# FeelingTheWord
FeelingTheWord is a web app that provides Bible verses based on emotions or life situations.
Users type how they are feeling, and the app returns a relevant verse to encourage, comfort, or guide them.

# Features
- Emotion-based Bible verse recommendations
- Clean, calming design
- Mobile responsive
- Built with HTML, CSS, and Vanilla JavaScript
- Lightweight and easy to use

# How it works 
The app analyzes keywords in the user input and maps them to predefined emotional categories. It then randomly selects a Bible verse from that category to display.
